# `@allforone/contracts`

Fonte única do contrato HTTP/portas/events (`api-shared-config.json`).

```ts
import { config } from '@allforone/contracts';
// ou
import config from '@allforone/contracts';
```

Dependência local: `"@allforone/contracts": "file:../../packages/contracts"` (a partir de `back-end/mss/*` ou `back-end/infra/*`; no front use `file:../../back-end/packages/contracts`).
