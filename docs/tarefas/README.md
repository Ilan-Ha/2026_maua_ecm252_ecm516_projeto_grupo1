# Tarefas de agentes

Cada sessão/task concluída deve deixar um arquivo aqui para o próximo agente não redescobrir o trabalho.

## Convenção

```
docs/tarefas/YYYY-MM-DD/
  NN-slug-curto.md
```

Exemplo: `docs/tarefas/2026-09-21/01-nestjs-catalog.md`

## Template mínimo

```markdown
# Título da task

- **Data:** YYYY-MM-DD
- **Agente/sessão:** descrição curta ou link do transcript
- **Branch:** nome se houver
- **Status:** done | partial | blocked

## O que foi feito
## Como foi feito
## Instruções (como operar / validar)
## Próximos passos
## Arquivos tocados
```
